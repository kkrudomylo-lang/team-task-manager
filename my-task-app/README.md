# Менеджер задач (Task Manager)

Лабораторная работа: упрощенный клон Jira/Trello. Вариант 15 (★★★).

## Технологии
- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **База данных:** SQLite (локальный файл `database.sqlite`)
- **Авторизация:** JWT-токены, хеширование паролей через `bcrypt`

## Как запустить проект
1. **Запуск бэкенда:**
   - Открой терминал в папке `server`.
   - Установи зависимости: `npm install`.
   - Запусти сервер: `node index.js`.
   - Сервер запустится на `http://localhost:8080`.

2. **Запуск фронтенда:**
   - Открой второй терминал в папке `my-task-app`.
   - Установи зависимости: `npm install`.
   - Запусти React: `npm run dev`.
   - Открой в браузере `http://localhost:5173`.

## Что реализовано
- Регистрация и вход пользователей (JWT).
- Создание проектов (роли: владелец).
- Kanban-доска (To Do, In Progress, Done).
- Задачи с исполнителями и сроками.
- Редактирование и удаление задач.
- Комментарии к задачам.
- Фильтрация задач по статусу, исполнителю и проекту (API).
- Журнал изменений (Changelog) при обновлении задач (API).
